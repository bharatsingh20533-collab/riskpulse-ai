# RiskPulse AI – Vendor Audit Intelligence System

## Overview
RiskPulse AI is an AI-powered audit intelligence dashboard designed to detect financial anomalies, monitor vendor risks, and improve audit efficiency through real-time insights.

## Features
- AI Risk Scoring
- Anomaly Detection
- Smart Alerts
- Vendor Risk Analysis
- Interactive Dashboard
- Trend Visualization

## Tech Stack
- HTML
- CSS
- JavaScript
- Chart.js

## Live Demo
https://bharatsingh20533-collab.github.io/riskpulse-ai/

## Problem Statement
Traditional audit systems are manual and reactive, making it difficult to identify fraud, duplicate transactions, and unusual vendor behavior in real time.

## Solution
This system uses rule-based anomaly detection and AI-driven risk scoring to proactively identify suspicious financial patterns and improve audit transparency.
